# Domain: CMake Build System\n\n**Quick Reference for CMake and build configuration in FalconFIX.**\n\n---\n\n## 🛡️ GOLDEN RULES\n\n**DON'T MODIFY** root `CMakeLists.txt` unless:\n1. You have approval in GitHub issue\n2. You explain clearly WHY\n3. You've tested locally first\n4. You provide rollback plan\n\n**DO USE** existing CMake helpers in `cmake/`\n\n---\n\n## 📁 Build Directory (Critical!)\n\n```powershell\n# ✅ CORRECT - Use persistent directory\ncmake --preset windows-debug\ncmake --build build/windows-debug --config Debug\n# Change code...\ncmake --build build/windows-debug --config Debug  # FAST! (incremental)\n\n# ❌ WRONG - Creating new directories\ncmake -B build-v1 -DCMAKE_BUILD_TYPE=Debug\ncmake --build build-v1\n# Later...\ncmake -B build-v2 -DCMAKE_BUILD_TYPE=Debug  # Recompiles EVERYTHING!\ncmake --build build-v2\n```\n\n**Goal**: Same `build/windows-debug/` directory always.\n\n---\n\n## 🔧 CMake Presets\n\n```powershell\n# List all\ncmake --list-presets\n\n# Configure (one-time per preset)\ncmake --preset windows-debug      # Debug with full symbols\ncmake --preset windows-release    # Release optimized\ncmake --preset linux-debug        # Linux debug\ncmake --preset linux-release      # Linux release\n\n# Fresh configure (clears cache)\ncmake --preset windows-debug --fresh\n```\n\n---\n\n## 🏗️ Building\n\n```powershell\n# Standard build\ncmake --build build/windows-debug --config Debug\n\n# Parallel (use all cores)\ncmake --build build/windows-debug --config Debug --parallel\n\n# Parallel with specific core count\ncmake --build build/windows-debug --config Debug --parallel 8\n\n# Specific target only\ncmake --build build/windows-debug --target falcon_fix_session\n\n# Verbose (see compiler commands)\ncmake --build build/windows-debug --verbose\n```\n\n---\n\n## ✏️ Adding a New Module\n\n### Step 1: Create Directory\n```powershell\nmkdir src/cpp/mymodule\nmkdir src/include/mymodule\nmkdir tests/mymodule\n```\n\n### Step 2: Create Module CMakeLists.txt\n\n```cmake\n# src/cpp/mymodule/CMakeLists.txt\n\nadd_lib(\n    TARGET falcon_fix_mymodule\n    SOURCES\n        MyClass.cpp\n        OtherClass.cpp\n    HEADERS\n        ${PROJECT_SOURCE_DIR}/src/include/mymodule/MyClass.h\n        ${PROJECT_SOURCE_DIR}/src/include/mymodule/OtherClass.h\n    DEPENDENCIES\n        fmt::fmt\n        spdlog::spdlog\n        OpenSSL::Crypto\n)\n```\n\n### Step 3: Register in Parent CMakeLists.txt\n\n```cmake\n# src/cpp/CMakeLists.txt (add this line)\nadd_subdirectory(mymodule)\n```\n\n### Step 4: Create Test CMakeLists.txt\n\n```cmake\n# tests/mymodule/CMakeLists.txt\n\nadd_test_executable(\n    TARGET MyModuleTests\n    SOURCES\n        MyClassTests.cpp\n        OtherClassTests.cpp\n    DEPENDENCIES\n        GTest::gtest_main\n        GTest::gmock\n        falcon_fix_mymodule  # Your new module!\n)\n```\n\n### Step 5: Register Test in Parent\n\n```cmake\n# tests/CMakeLists.txt (add this line)\nadd_subdirectory(mymodule)\n```\n\n### Step 6: Build & Test\n\n```powershell\ncmake --build build/windows-debug --config Debug\nctest --preset windows-debug -R MyModuleTests --output-on-failure\n```\n\n---\n\n## 📚 CMake Helper Macros\n\n### add_lib() - Create library\n\n```cmake\nadd_lib(\n    TARGET falcon_fix_session           # Library name\n    SOURCES\n        Session.cpp\n        SessionManager.cpp\n    HEADERS\n        ${PROJECT_SOURCE_DIR}/src/include/session/Session.h\n        ${PROJECT_SOURCE_DIR}/src/include/session/SessionManager.h\n    DEPENDENCIES\n        fmt::fmt                        # External\n        spdlog::spdlog                  # External\n        falcon_fix_socket               # Internal (other module)\n)\n```\n\n### add_app() - Create executable\n\n```cmake\nadd_app(\n    TARGET my_application\n    SOURCES\n        main.cpp\n        app.cpp\n    DEPENDENCIES\n        falcon_fix_session\n        fmt::fmt\n    INSTALL TRUE\n)\n```\n\n### add_test_executable() - Create test\n\n```cmake\nadd_test_executable(\n    TARGET MyModuleTests\n    SOURCES\n        MyClassTests.cpp\n        FeatureTests.cpp\n    DEPENDENCIES\n        GTest::gtest_main\n        GTest::gmock\n        falcon_fix_mymodule\n)\n```\n\n### add_benchmark_executable() - Create benchmark\n\n```cmake\nadd_benchmark_executable(\n    TARGET SessionBenchmark\n    SOURCES\n        SessionBenchmark.cpp\n    DEPENDENCIES\n        benchmark::benchmark\n        falcon_fix_session\n)\n```\n\n---\n\n## 📦 Adding External Dependencies\n\n**DISCUSS FIRST** in GitHub issue before adding!\n\n### If Approved:\n\n1. Update README-BUILD.md with prerequisites\n\n4. Test on multiple platforms\n\n---\n\n## 🎛️ Build Options\n\n```cmake\n# Set in preconfigure step\ncmake --preset windows-debug -D FALCONFIX_BUILD_TESTS=ON\n\n# Available options in root CMakeLists.txt:\noption(FALCONFIX_BUILD_TESTS \"Build unit tests\" ON)\noption(FALCONFIX_BUILD_BENCHMARKS \"Build benchmark targets\" ON)\noption(FALCONFIX_CODE_COVERAGE \"Enable code coverage\" ON)\n```\n\n---\n\n## ⚙️ Build Flags\n\n### Debug Build (Automatic)\n```\n/Zi                 # Full debug symbols\n(no optimization)   # O0 equivalent\n```\n\n### Release Build (Automatic)\n```\n/O2 /DNDEBUG /utf-8                    # MSVC\n/OPT:REF /OPT:ICF                      # Link-time optimization\n\n-O3 -march=native -DNDEBUG             # GCC/Clang\n-flto                                  # Link-time optimization\n```\n\n### Code Coverage (If Enabled)\n```\n/Zi                 # MSVC (OpenCppCoverage handles rest)\n--coverage          # GCC/Clang\n```\n\n---\n\n## 🧹 Cleaning\n\n```powershell\n# Partial clean (targets only) - FAST\ncmake --build build/windows-debug --target clean\n\n# Full clean (last resort) - SLOW\nrm -Path build/windows-debug -Recurse -Force\ncmake --preset windows-debug\ncmake --build build/windows-debug --config Debug\n```\n\n---\n\n## 🐛 Troubleshooting\n\n### \"VCPKG_ROOT not defined\"\n```powershell\n$env:VCPKG_ROOT = \"C:\\path\\to\\vcpkg\"\n```\n\n### \"Could not find GTest\"\n```powershell\ncd build/windows-debug\n$env:VCPKG_ROOT/vcpkg integrate install\ncmake --preset windows-debug --fresh\n```\n\n### \"Compiler not found\"\n```powershell\n# Use Developer Command Prompt for VS 2026\n# Or explicitly specify:\ncmake -G \"Visual Studio 17 2022\" .\n```\n\n### Incremental build recompiles everything\n```\nCauses:\n- CMakeLists.txt modified (rebuild needed - OK)\n- vcpkg updated (rebuild needed - OK)\n- Build cache corrupted (need full rebuild)\n\nSolution:\nrm -Path build/windows-debug -Recurse -Force\ncmake --preset windows-debug\ncmake --build build/windows-debug --config Debug\n```\n\n### Linker error \"unresolved external\"\n1. Check CMakeLists.txt DEPENDENCIES section\n2. Is the library built?\n3. Is the .lib/.a file generated?\n4. Run with verbose: `cmake --build . --verbose`\n\n---\n\n## 📊 VSCode CMake Integration\n\n```json\n// .vscode/settings.json\n{\n  \"cmake.generator\": \"Visual Studio 17 2022\",\n  \"cmake.configureArgs\": [\"-DVCPKG_ROOT=<your-vcpkg-path>\"]\n}\n```\n\n---\n\n## ✅ Checklist When Modifying CMake\n\n- [ ] Modification is necessary (non-negotiable?)\n- [ ] Discussed in GitHub issue\n- [ ] Tested locally first\n- [ ] No build warnings introduced\n- [ ] Incremental build still works\n- [ ] Commit message explains WHY\n- [ ] No root CMakeLists.txt touched (unless critical)\n\n---\n\n## 📚 Resources\n\n- [CMake Official](https://cmake.org/cmake/help/latest/)\n- [vcpkg](https://github.com/Microsoft/vcpkg)\n- Full guide: `CMAKE_GUIDE.md` in project root\n"
